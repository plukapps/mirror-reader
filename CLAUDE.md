## Notas para Claude Code

- Leer `specs/README.md` y el spec del requisito antes de tocar código.
- Usar primero los skills de addyosmani incluidos en el proyecto (`.claude/skills/`), según la tabla "Skills preferidos" de AGENTS.md. Solo recurrir a skills de otros orígenes (por ejemplo superpowers) cuando el proyecto no tenga uno equivalente.
- Mantener `KANBAN.md` actualizado en cada paso, tal como indica AGENTS.md. No empezar una tarea sin mover su tarjeta.
- Los planes se guardan en `specs/plans/`, no en `docs/superpowers/`.
- No hacer `git init`, commits ni pushes sin que el usuario lo haya aprobado en el plan o lo pida.
